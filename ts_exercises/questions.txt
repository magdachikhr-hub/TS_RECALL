სწავლის შედეგი 2 : TypeScript-ის საბაზისო
კონსტრუქციები
2.1 — ტიპიზებული ცვლადები
შექმენით:
• წიგნის სათაური (string)
• გამოცემის წელი (number)
• ბიბლიოთეკაში არსებობის სტატუსი (boolean)
• გვერდების რაოდენობა (number)
გამოიტანეთ ყველა მნიშვნელობა კონსოლში.
2.2 — ფუნქცია და დასაბრუნებელი ტიპი
შექმენით getBookInfo ფუნქცია, რომელიც პარამეტრებად მიიღებს წიგნის
მონაცემებს და დააბრუნებს ფორმატირებულ ტექსტს (დააზუსტეთ დასაბრუნებელი
ტიპი).

2.3 — if / else პირობა
შექმენით getBookSize ფუნქცია, რომელიც გვერდების რაოდენობის მიხედვით
დააბრუნებს:
• "Short" (200-მდე)
• "Medium" (200–500)
• "Long" (500-ზე მეტი)
2.4 — მასივი და ციკლი
შექმენით 5 წიგნის ავტორის string[] მასივი და for ციკლით გამოიტანეთ
თითოეული ელემენტი ინდექსთან ერთად.
2.5 — ციკლი და ფილტრაცია
შექმენით number[] მასივი 6 წიგნის შეფასებით და for...of ციკლით გამოთვალეთ
საშუალო შეფასება.

სწავლის შედეგი 3 : Type Alias და Interface
3.1 — Type Alias
შექმენით TBook type alias შემდეგი ველებით:
• id
• title
• genre
• pages
• price
3.2 — Interface
შექმენით IAuthor interface შემდეგი ველებით:
• firstName
• lastName
• country
• birthYear
• website? (არასავალდებულო ველი)

3.3 — ობიექტები და მონაცემების ასახვა
შექმენით:
• author ობიექტი IAuthor ინტერფეისის მიხედვით;
• book ობიექტი TBook ტიპის მიხედვით.
ორივე ობიექტის ინფორმაცია გამოიტანეთ კონსოლში.
3.4 — ობიექტების მასივი
შექმენით TBook[] მასივი 3 წიგნით და forEach-ით გამოიტანეთ თითოეული წიგნის
სათაური და ფასი.

სწავლის შედეგი 4 : კლასები და OOP
4.1 — Member კლასი
შექმენით Member კლასი შემდეგი თვისებებით:
• firstName
• lastName
• email
• age
გამოიყენეთ constructor და წვდომის მოდიფიკატორები (public, private).
4.2 — ობიექტის შექმნა
შექმენით Member კლასის ობიექტი და გამოიტანეთ მისი ინფორმაცია კონსოლში.
4.3 — მემკვიდრეობითობა
შექმენით PremiumMember კლასი Member კლასის მემკვიდრეობით (extends) და
დაამატეთ getBorrowedBooks() მეთოდი, რომელიც დააბრუნებს ნასესხები წიგნების
სიას.
4.4 — კლასის მეთოდი
Member კლასში დაამატეთ getProfile() მეთოდი, რომელიც დააბრუნებს წევრის
სრულ ინფორმაციას ფორმატირებული ტექსტის სახით.

გამოიძახეთ getProfile() როგორც Member, ისე PremiumMember კლასის
ობიექტებისთვის.
